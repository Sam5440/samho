## 验收范围

- 11 份中文文档、中文导航、全文搜索、逐篇渲染、代码块与离线阅读。
- 7 组、47 项范围的全选、推荐首期、清空、单项选择、依赖缺口提示和三种实现状态。
- 目标、优先级、预算、平台、场景、调用轨迹策略、操作约束与补充说明进入中文计划。
- 空范围禁止导出；修改字段或勾选后旧导出失效；依赖提示不会擅自补选。
- 实际下载文件为 UTF-8 BOM，与浏览器预览逐字一致；测试下载已清理，不构成用户执行授权。
- 复制全文经实际浏览器点击确认成功；Node 测试覆盖复制调用和复制内容一致性。
- 用户备注中的 HTML 保持纯文本；文档渲染不执行 HTML 或 `javascript:` 链接。
- 计划页在 1710×934、560×900、375×900 下没有横向溢出；文档页 375×900 没有横向溢出。
- `/docs`、`/plan` 及静态别名均返回 UTF-8；13 条静态路由逐字匹配最终本地文件，避免旧二进制内嵌资料。
- 文档与计划页操作没有任何 `/api/` 请求，没有浏览器错误或警告；没有运行 Agent、工具或真实模型任务。

## 复现

先启动本地服务，另开终端运行测试：

```powershell
target/release/samho.exe serve --bind 127.0.0.1:374
node --test scripts/test-chinese-pages.mjs
node scripts/test-chinese-browser.mjs http://127.0.0.1:374
```

浏览器脚本使用 Node 22 内置 WebSocket/CDP，不依赖 npm 包。默认查找本机 Chrome，可通过 `SAMHO_CHROME` 环境变量指定可执行文件；测试使用独立临时浏览器配置，不修改用户的浏览器配置。它只检查文档和计划，不调用任务 API。

原始结果见 [browser-validation.json](browser-validation.json)，截图见 [桌面计划页](plan-1710.png)、[560 像素计划页](plan-560.png)、[375 像素计划页](plan-375.png)、[375 像素文档页](docs-375.png)。

此轮验证针对中文交付与计划编排。完整 MCP 可选能力、真实模型质量、Pi/Rust 对照性能、跨平台 TUI 和 24 小时稳定性验收仍按实现状态文档保留为后续范围。网页只生成文本；用户将完整文本回传当前对话后，才按该范围继续实施。
