# 目标模型 · UI 迭代验收清单（goal model）

> 逐项验收：每完成一项任务，回到本表核对证据；未过项继续迭代，直到全部 PASS。

## G1 工具调用渲染：ZCode 风格默认折叠
- **范围**：timeline 中所有工具调用（tool:read/write/shell 等）、skill 调用（load_skill）、MCP 调用（tool:mcp:*）、命令执行（shell）。
- **标准**：
  - 默认渲染为一行紧凑摘要（图标 + 工具名/目标 + 状态点），不展开参数与输出。
  - 点击行展开完整参数/输出；再次点击折叠。状态（运行中/完成/失败）在行内可见。
  - 运行中的调用有进行中指示；完成后自动收起为摘要。
- **验收证据**：GUI 截图（折叠态 + 展开态）。

## G2 右侧栏新增「子代理」+「任务看板」面板
- **子代理面板**：展示运行时子代理/并发任务 span（来源：轨迹事件/任务快照），含状态与最近活动。
- **任务看板**：展示当前工作区任务列表（running/queued/done/failed），含进度轮次，可取消运行中任务。
- **位置**：右栏检查组 tab（与 轨迹/对象/MCP/技能/模型 并列）。
- **验收证据**：面板截图 + 数据来自真实 API。

## G3 全 UI 截图审查（美学 + 无 bug）
- **覆盖**：暗/亮主题 × 默认页、全部 9+2 个右栏面板、新建工作区对话框（目录选择器）、设置对话框、模型选择命令面板、375px 窄屏。
- **标准**：排版层级清晰、间距一致、无溢出/截断/重叠、对比度可读、交互无报错（unhandledrejection 为空）。
- **验收证据**：截图集 + 每张检查结论；发现问题→修复→复检。

## G4 质量门
- cargo test --workspace 全绿、clippy 0 警告、fmt 干净、前端 ESM 解析通过。
- 全部改动提交 git。

## G5 完成审计
- 本表逐项对照实际证据（截图/命令输出），无「未验证」项后才算完成。
