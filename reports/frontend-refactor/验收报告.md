## 验收过程中发现并修复的缺陷

| 缺陷 | 根因 | 修复 |
|------|------|------|
| D-G1 组件 `hidden` 属性失效（停止按钮永不消失、回到底部按钮常显） | base.css 无 `[hidden]` 规则，组件显式 `display:inline-flex` 覆盖 UA 样式 | base.css 增加 `[hidden] { display: none !important; }` |
| D-G2 任务失败后 composer 卡运行态（首例任务被网络策略拒绝） | 同 D-G1（cancelBtn 隐藏失效） | 同上；另外 finishTask 已正确执行，症状消失 |
| D-G3 草稿任务落库后时间线丢失最终消息 | finishTask 仅在 `!task.sessionId` 时切换会话视图，但 applyProgress 已先填 sessionId | finishTask 改为：currentSessionId ≠ resultSession 即 loadSession 切换 |
| D-G4 切换会话后轨迹恒为空 | loadSession 把事件对象（而非 trace_id 字符串）传入 collectTraceEvents | 传 `latestTrace?.trace_id \|\| ''` |
| D-G5 工具卡展开按钮渲染抛 `button is not defined`，导致会话加载后时间线不渲染 | timeline/tools.js 使用 button 未导入 | 补充 import |
| D-G6 live 进程流完全不可见（无流式文本/思考，轨迹只有完成帧） | 模型级 `streaming` 字段默认 false，agent 走 complete_typed 非流式路径 | runtime.toml 每个模型加 `streaming = true`（配置问题，非代码缺陷） |
| D-G7 失败任务在时间线无任何可见痕迹 | 服务端失败时不产生 assistant 消息 | finishTask 在时间线追加 `{role:'error'}` 注记行（红字 note）+ toast |

另：网络策略禁止对非回环主机明文 HTTP（工作正常，非缺陷）——验收运行时通过 `D:\ddcode\rpi-tests\forwarder.py`（9600→wuyou）回环转发接入网关。

## 已知边界（非缺陷）

- GLM 思考内容长短由上游决定：简单任务可能只思考一句话甚至不思考（已两次实测），思考块 UI 对 0 长度自动隐藏。
- gpt-6.1-sol 经该网关不下发 reasoning 增量（仅 content），思考块相应不显示。
- LaTeX 公式（`$$…$$`）按原文本渲染，未接入公式库（与 CSP 无构建约束一致，后续可选渐进增强）。
- 思考块耗时徽标（reasoning-duration）依赖后端 `reasoning_ms`，当前后端未下发，显示为空。
