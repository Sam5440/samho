## 0. 范围与原则

1. 全部真实模型调用使用用户提供的测试网关；单任务 `max_output_tokens ≤ 4096`，控制 token 消耗。
2. 不削弱既有安全边界（回环绑定、跨源拒绝、非回环 HTTP 禁令、脱敏）。网关仅支持 HTTP，因此用**本地回环 TCP 转发器**桥接（`http://127.0.0.1:{port}/v1` → `http://wuyou.cloud.isam.top:3000`），不改安全代码。
3. 测试工件放 `D:\ddcode\rpi-tests\`（仓库外），避免污染仓库；最终报告与证据副本存 `reports/testing/`。
4. 每个缺陷登记编号（D-xx），修复后必须回归（cargo test 93 项 + Node 13 项 + 针对性复测）。
5. 诚实报告：fixture 通过 ≠ 真实模型通过；未验收项如实标注。
